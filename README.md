# بدّل حرف — نسخة الويب الجاهزة للنشر

هذا مشروع React كامل (مبني بـ Vite) متصل بـ Firebase حقيقي بدل نظام
`window.storage` الخاص بـ Claude. جاهز يُرفع كموقع حقيقي بدومين خاص.

## ١. التركيب محليًا (اختياري، للتجربة قبل النشر)

يحتاج جهازك [Node.js](https://nodejs.org) مثبّت (نسخة 18 فما فوق).

```bash
npm install
npm run dev
```

بيفتح لك رابط محلي (عادة `http://localhost:5173`) تقدر تجرب فيه اللعبة
كاملة متصلة بقاعدة بياناتك الحقيقية على Firebase.

## ٢. تحديث قواعد الأمان بـ Firebase (مهم جدًا قبل النشر الفعلي)

حاليًا قاعدة البيانات شغالة بـ"Test mode" اللي تنتهي صلاحيته تلقائيًا خلال
أيام وتصير كل البيانات مقفولة. لازم تستبدلها بالقواعد الحقيقية:

1. روح لـ [Firebase Console](https://console.firebase.google.com) → مشروع
   `linguist-d4211` → Firestore Database → تبويب **Rules**
2. امسح المحتوى الموجود، والصق محتوى ملف `firestore.rules` المرفق هنا
3. اضغط **Publish**

## ٣. النشر (اختر واحد)

### الخيار الأول: Vercel (الأسهل، مجاني)
1. أنشئ حساب على [vercel.com](https://vercel.com) (تقدر تسجل بحساب GitHub مباشرة)
2. ارفع هذا المجلد كمستودع على GitHub (أو استخدم Vercel CLI: `npx vercel`)
3. من لوحة Vercel: New Project → اختر المستودع → Deploy
4. بعد النشر تحصل على رابط مباشر (`your-project.vercel.app`)، وتقدر تربط دومين خاص بك من Settings → Domains

### الخيار الثاني: Netlify (بنفس السهولة)
1. حساب على [netlify.com](https://netlify.com)
2. اسحب مجلد المشروع مباشرة على الموقع (Netlify Drop) بعد ما تشغّل `npm run build`
   محليًا — أو اربطه بـ GitHub زي Vercel

كلا الخيارين عندهم خطة مجانية تكفي هذا الحجم من الاستخدام بسهولة.

## ٤. دومين خاص

بعد ما يصير عندك رابط شغال (Vercel/Netlify)، تقدر تشتري دومين (من Namecheap،
GoDaddy، أو أي مزوّد) وتربطه من إعدادات المشروع بنفس المنصة (Vercel/Netlify) —
خطوات واضحة ومباشرة بلوحة التحكم عندهم.

## ملاحظات مهمة

- **مفاتيح Firebase الموجودة بـ `src/storage.js` ليست سرًا** — هذا طبيعي
  لتطبيقات الويب، الحماية الحقيقية من قواعد الأمان (`firestore.rules`) مو
  من إخفاء المفتاح.
- الخطة المجانية من Firebase (Spark) سخية جدًا وتكفي آلاف المستخدمين شهريًا
  بدون أي تكلفة، لكن راقب استخدامك من لوحة Firebase لو توسّعت اللعبة كثير.
- لو حبيت تطبيق جوال حقيقي بالمستقبل (زي تطبيق لمّة على App Store)، هذا
  خطوة إضافية منفصلة (باستخدام Capacitor مثلاً) — قول لي إذا وصلت لهالمرحلة.
